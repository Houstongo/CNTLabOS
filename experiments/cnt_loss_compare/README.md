# Deprecated CNT Experiment

`experiments/cnt_loss_compare` is a legacy experiment line.

It should not be selected as the default CNT model directory for new work.

Use `experiments/cnt_paper_repro` for current CNT model development unless the task explicitly says to work on the legacy loss-comparison pipeline.

This directory may still exist temporarily because some configs or tools still reference assets or datasets under `cnt_loss_compare`.
