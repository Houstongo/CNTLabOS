# 数据清洗看片台设计

**目标**

把“数据清洗”页面重构成以图像查看为核心的看片台，而不是把图片、步骤图和判断信息硬塞进同一块可拖动区域。用户进入页面后，应先看到完整原图，再逐步查看 ROI、二值图、骨架图和曲率叠加图，并能随时点击放大。

**核心原则**

1. 原图优先：上半区的最大视觉权重给原图，不让判断卡片挤压主图。
2. 步骤可验：中间步骤图独立成缩略带，明确步骤名称和作用。
3. 判断收缩：清洗分数、五个特征和风险命中压缩到右侧窄栏，只保留最关键结论。
4. 放大查看：原图和步骤图都支持点击放大，在遮罩层中查看完整图像，不依赖页面滚动或拖动。

**页面布局**

1. 顶部保留筛选条和样品列表，不改数据清洗入口。
2. 主体改为上下结构：
   - 上半区：左侧原图大图，右侧判断摘要。
   - 下半区：步骤缩略图条。
3. 放大图通过全屏遮罩弹层展示，支持关闭。

**交互规则**

1. 选择样品后，原图立即刷新，右侧判断信息同步刷新。
2. 原图点击后进入放大查看。
3. 步骤图点击后进入同一套放大查看器。
4. 步骤图加载失败时，单独在步骤区提示，不影响原图和判断显示。

**信息收缩策略**

右侧判断区只保留三块：

1. 可信度结论与分数
2. 五个特征值
3. 最多三条关键风险命中，其余折叠

**预期效果**

1. 用户在不滚动主图区域的情况下能看清原图主体。
2. 中间步骤图不会再缩得看不清。
3. 核心图像都支持放大，适合人工验图。
