# 100000x CNTSegNet Paper Reproduction Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a dedicated `100000x` paper-reproduction pipeline that uses `768x768` patches, a `ResNet34-U-Net` backbone, FFT-based orientation loss, and the paper-style two-phase training schedule.

**Architecture:** Reuse the curated `100000x` image-level dataset as the source of truth, derive a separate patch dataset under `experiments/cnt_paper_repro`, and keep all reproduction-specific model, loss, training, and evaluation code isolated from the existing `cnt_loss_compare` framework. The reproduction line uses current `WCNTSegNET` weak masks as supervision assets but changes the backbone, patching strategy, orientation loss, and training schedule to follow the paper.

**Tech Stack:** Python, PyTorch, torchvision, OpenCV, NumPy, existing `lab_agent` conda environment
