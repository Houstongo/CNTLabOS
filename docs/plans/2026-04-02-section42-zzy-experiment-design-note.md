# 4.2 ZZY 组实验步骤与实验设计写作说明

## 目标

本文档用于整理 `ZZY` 组实验设计在论文第 `4.2` 节中的写法，明确：

- 哪些内容应在 `4.2` 中交代
- `ZZY` 组的初始参数空间应如何描述
- 实际样本覆盖应如何说明
- 如何与第 `4.4` 节“知识增强参与参数收敛”形成逻辑衔接

建议第 `4.2` 节的角色定义为：

- 交代实验设计思路
- 说明初始参数空间
- 说明实验步骤与观察尺度
- 不在此节完成最终参数收敛

最终的背景条件固定与核心变量筛选，建议放到第 `4.4` 节结合知识增强模块与少量预实验来展开。

## 建议的章节逻辑

推荐全文逻辑如下：

- `4.2`：给出初始实验设计与候选参数空间
- `4.3`：给出自动化图像表征方法与关键形貌提取
- `4.4`：在候选参数空间基础上，结合知识增强分析和预实验结果进行参数收敛，并开展工艺-形貌关系分析和建模

也就是说：

- `4.2` 回答“最初实验是怎么设计出来的”
- `4.4` 回答“为什么最终固定这组背景条件，并重点分析这几个变量”

## ZZY 组初始参数空间

基于数据库 `cnta_experiments.sqlite` 中 `source='ZZY'` 且未逻辑删除的样本，当前 `ZZY` 组的完整候选参数空间可整理为：

### 1. 成像倍率

- `10000x`
- `50000x`
- `100000x`

另有极少量异常记录 `50002`，不作为正式实验设计空间描述。

### 2. 氧化铝相关参数

- `Al2O3 power`: `50 W`, `200 W`
- `Al2O3 thickness`: `5 nm`, `10 nm`, `15 nm`, `30 nm`

### 3. 铁催化剂相关参数

- `Fe power`: `2 W`, `5 W`, `10 W`, `20 W`, `30 W`, `40 W`, `50 W`
- `Fe thickness`: `0.5 nm`, `0.75 nm`, `1.0 nm`, `1.25 nm`, `1.5 nm`, `1.75 nm`, `2.0 nm`, `2.25 nm`, `2.5 nm`, `2.75 nm`

### 4. 气氛条件

数据库中 `Ar/H2/C2H4` 实际为联动的三档组合，而非完全独立自由变量：

- `600 / 300 / 150`
- `400 / 200 / 100`
- `200 / 100 / 50`

### 5. 热处理与生长条件

- `anneal_temp = 600 ℃`
- `anneal_time = 15, 30, 45 min`
- `growth_temp = 750 ℃`
- `growth_time = 3 h`

## 实际样本覆盖特点

在论文中建议明确区分：

- **初始候选参数空间**
- **实际样本覆盖分布**

因为当前 `ZZY` 组并不是在全部参数组合上均匀采样，而是呈现出较明显的主工作区间和补充覆盖结构。

### 1. 气体组合分布

- `600/300/150`: `289`
- `400/200/100`: `63`
- `200/100/50`: `12`

说明主工作区间集中在高流量组合，其他两档主要起到补充探索作用。

### 2. 氧化铝参数分布

- `Al2O3 power = 200 W`, `Al2O3 thickness = 5 nm`: `336`
- 其他氧化铝参数组合样本明显较少

说明当前数据的主要工作区间集中在 `200W + 5nm` 这组背景条件附近。

### 3. Fe 功率分布

- `5 W`: `238`
- `10 W`: `34`
- `20 W`: `38`
- `2 W`: `16`
- `30 W`: `17`
- `40 W`: `5`
- `50 W`: `16`

说明 `5W` 是主覆盖区间，其余档位用于补充观察工艺响应。

### 4. Fe 厚度分布

样本主要集中在：

- `1.0 nm`
- `2.0 nm`

其余厚度为辅助覆盖点。

### 5. 倍率分布

当前 `ZZY` 组同时包含 `10000x`、`50000x` 和 `100000x`，其中：

- `10000x` 更适合观察阵列整体覆盖与网络分布
- `50000x` 更适合兼顾局部弯曲形态与整体取向信息
- `100000x` 更适合观察更细尺度局部结构

因此，`50000x` 更适合用于后续工艺-形貌关系分析主线。

## 4.2 推荐写法

### 本节建议强调的内容

1. `ZZY` 组采用了多因素、多尺度的实验设计  
   包含催化剂参数、气氛条件、退火时间以及多倍率成像。

2. 初始参数空间覆盖了氧化铝支撑层、铁催化剂、气体组合和热处理条件等多个层面  
   其目的在于探索不同工艺条件对 CNT 阵列结构与性能的影响。

3. 不同倍率承担不同观测任务  
   - `10000x`：整体覆盖与网络分布
   - `50000x`：局部弯曲与整体取向
   - `100000x`：更细尺度结构细节

4. 当前样本覆盖并非完全均匀  
   存在主工作区间与补充探索点，这为后续参数收敛与变量筛选提供了基础。

### 建议在正文中使用的表述

可直接使用下面这段：

> 为系统考察工艺因素对 CNT 阵列结构与性能的影响，本文在 `ZZY` 组中设计了包含催化剂参数、气氛条件、退火时间及多倍率成像的多因素实验方案。初始候选参数空间涵盖 `Al2O3 power`、`Al2O3 thickness`、`Fe power`、`Fe thickness`、`Ar/H2/C2H4`、`anneal_temp`、`anneal_time`、`growth_temp` 和 `growth_time` 等变量，同时采集 `10000x`、`50000x` 和 `100000x` 三种尺度下的 SEM 图像，以分别表征阵列整体分布、局部弯曲形态与细尺度结构特征。需要说明的是，当前实验样本在参数空间中的覆盖并非完全均匀，而是呈现出若干主工作区间与补充探索点相结合的特点，这也为后续参数收敛和重点变量筛选提供了基础。

## 4.2 与 4.4 的衔接建议

建议在 `4.2` 结尾增加一个过渡句，将逻辑引向第 `4.4` 节。

推荐写法：

> 在上述初始实验设计基础上，后续章节将进一步结合知识增强分析、少量预实验结果及样本分布特征，对参数空间进行收敛，并在固定背景条件下开展工艺参数与关键形貌特征之间的关系分析与建模。

## 为什么最终不在 4.2 直接给出固定背景条件

建议不要在 `4.2` 里直接把：

- `Al2O3 power = 200 W`
- `Al2O3 thickness = 5 nm`
- `Ar/H2/C2H4 = 600/300/150`
- `anneal_temp = 600`
- `growth_temp = 750`
- `growth_time = 3 h`

写成“实验一开始就确定好的唯一条件”，因为更真实的逻辑是：

1. `4.2` 给出初始候选空间与实验设计
2. 第 `3` 章知识增强模块提供参数收敛的先验方向
3. 结合少量预实验和当前数据分布
4. 最终在 `4.4` 中完成背景条件固定与核心变量筛选

这种写法更符合科研过程，也更容易解释为什么后续重点分析：

- `Fe power`
- `Fe thickness`
- `anneal_time`

## 最终建议

可将第 `4.2` 节理解为：

- “实验方案与候选参数空间说明”

而将第 `4.4` 节理解为：

- “知识增强参与参数收敛、关系建模与结果解释”

这样既能避免章节内容重复，也能让第 `3` 章、第 `4` 章之间形成更清晰的承接关系。
